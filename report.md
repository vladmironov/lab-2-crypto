## Лабораторная работа 2. Теоретическая часть

Сегодня на рассмотрении алгоритм встраивания LSB и исследование изменения изображения при встраивании данных этим алгоритмом.

Алгоритм **LSB** - это метод сокрытия информации, при котором биты секретного сообщения поочерёдно записываются на место младших значащих битов (LSB) пикселей изображения

Первое, что мы сделали - написали класс LSB как исходный алгоритм замены младшего бита. Ознакомиться с ним можно в папке проекта **/src/lsb.py**

В данном классе все реализуется в блоках ''\_\_init\_\_'' и ''bits''. Все основывается на двух операциях:
- Взятие младшего бита из исходного байта (числового значения)
- Его замена операцией bit = (bit & 0xFE) | m (m - секретный бит)

**0xFE = 11111110<sub>2</sub>**

```python
mask = 0xFE

class LSB:
    def __init__(self, x):
        self.state = x

    def bits(self, m):
        self.state = (self.state & mask) | m
        return self.state
```

Для проверки вы можете запустить файл **/src/text.py**. В нем есть исходный текст и его извлечение

```python
import numpy as np
from PIL import Image
from lsb import LSB

arr = np.array(Image.open("img/gradient.png").convert("RGB"))
flat = arr.reshape(-1)

msg = b"hello, world"
bits = np.unpackbits(np.frombuffer(len(msg).to_bytes(4, "big") + msg, dtype=np.uint8))

if bits.size > flat.size:
    print(f"не помещается: нужно {bits.size}, есть {flat.size}")
    exit()

op = LSB(0)
for i in range(bits.size):
    op.state = int(flat[i])
    flat[i] = op.bits(int(bits[i]))

length = int.from_bytes(np.packbits(flat[:32] & 1).tobytes(), "big")
ext = np.packbits(flat[:32 + length * 8] & 1).tobytes()[4:]

print("текст:", msg.decode())
print("извлечение:", ext.decode())
```

В предыдущей работе мы упоминали алгоритм **AES**. Сегодня мы будем использовать AES-CTR для шифрования исходного сообщения.

Напомню, что для реализации AES-CTR мы используем библиотеку **pycryptodome**. Мы для облегчения задачи взяли за основу функции шифрования/расшифрования из материалов предыдущей работы

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

def aes_ctr_encrypt(plain: bytes, key: bytes):
    nonce = get_random_bytes(8) # 8 байт nonce
    cipher = AES.new(key, AES.MODE_CTR, nonce=nonce)
    ciphertext = cipher.encrypt(plain)
    return ciphertext, nonce

def aes_ctr_decrypt(ciphertext: bytes, key: bytes, nonce: bytes):
    cipher = AES.new(key, AES.MODE_CTR, nonce=nonce)
    return cipher.decrypt(ciphertext)
```

Первая - **metrics.py**. С помощью неё и библиотек scikit-image и scipy мы реализовываем вычиление нужных нам метрик. Мы будем вычислять следующие параметры:
- PSNR - соотношение ''сигнал против шума''. Значение покажет нам, насколько сильно стего-картинка отличается от оригинала на уровне пикселей
- SSIM - индекс структурного сходства. Значение покажет нам визуальное сходство двух картинок
- Изм. - доля изменённых пикселей
- P(LSB=1) - вероятность того, что младший бит равен единице
- Chi2 - Хи-квадрат (показатель, проверяющий, насколько часто встречаются пары соседних значений яркости)
- p-val - результат теста по хи-квадрату. Покажет нам, что младшие биты распределены случайно.

Что мы можем сказать по итогам нашего эксперимента?
- При малом объеме сообщения PSNR очень высокий, и он падает при увеличении объема
- Значение SSIM никак не поменяется при смене объема изображения
- При малом объеме поменяется мизерное количество пикселей. При увеличении объема сообщений количество изменяемых пикселей будет расти
- При встраивании зашифрованного текста вероятность становится ближе к 0.5, так как шифртекст — это случайный шум
- Шифрование меняет статистику сильнее, чем открытый текст
- Случайный LSB распределяет ошибки по всей картинке, что делает их еще более незаметными для визуального и статистического анализа
- Статистические метрики с ростом объема данных показывают, что скрыть факт наличия данных становится сложнее
