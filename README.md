# Лабораторная работа 2 по криптографии

**Вашему вниманию представлена лабораторная работа с исследованием изменения изображения при встраивании данных методом LSB**

## Инструкция

Убедитесь, что у вас установлен Python версии 3.13+

Перед запуском выполните следующую команду:

``` powershell
python -m pip install numpy pillow pycryptodome matplotlib scikit-image scipy
```

и очистите кэш командой

```powershell
python -m pip cache purge
```

Файл для запуска - **main.py**. В нем реализована вся необходимая логика.

Результаты выполнения работы записываются в следующие папки:
- crypt/
- results/ (в этой папке лежат гистограмма и difference)

Запустите программу командой

```powershell
python src/main.py
```

Для проведения эксперимента со своим изображением предлагаем следующее:

**Добавьте название исследуемого изображения**. В строке 

```python
imgs = ["gradient.png", "noise_texture.png"]
```

через запятую, в кавычках, внутри квадратных скобок впишите название своего файла. Изображение обязательно должно быть не меньше 256х256 пикселей 

**Приятного использования!**
