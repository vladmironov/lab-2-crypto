# Лабораторная работа 2 по криптографии

**Вашему вниманию представлена лабораторная работа с исследованием изменения изображения при встраивании данных методом LSB**

## Инструкция

Убедитесь, что у вас установлен Python версии 3.13+

Перед запуском выполните следующую команду:

``` powershell
python -m pip install numpy pillow pycryptodome matplotlib scikit-image scipy
```

и очистите кэш командой


```powershell
python -m pip cache purge
```

Файл для запуска - **main.py**. В нем реализована вся необходимая логика.

Результаты выполнения работы записываются в следующие папки:
- crypt/
- results/ (в этой папке лежат гистограмма и difference)

Запустите программу командой

```powershell
python src/main.py
```

**Важно!** Программа не заточена под выполнение единожды. Для проверки результатов под разные сообщения и разные записи в файлы предлагаем следующий вариант изменений:

**1. Поменяйте сообщение.** В main.py для этого в строке

```python
msg = b"Hello world"
```

необходимо заменить **только то, что лежит в кавычках!** Для того, чтобы увеличить эту строку (для наглядности результата) можно сделать следующее:

```python
msg = b"Hello world" * 100
```

Эта строка продублирует "Hello world" 100 раз

**2. Поменяйте записываемый файл**. Вместо "metrics.csv" в строке

```python
with open("results/metrics.csv", "w", newline="", encoding="utf-8-sig") as f:
```

вы можете написать любое название вашего файла (существующего или программа создаст сама)

**Предупреждение!** Если вы не меняете название файла, программа перезапишет исходный файл. Будьте аккуратны, чтобы избежать потери данных

**3. Поменяйте название исследуемого изображения**. В строке 

```python
img = np.array(Image.open("img/gradient.png").convert("RGB"))
```

вместо **gradient.png** впишите название своего файла. Изображение обязательно должно быть не меньше 256х256 пикселей
